# data2 Sand Point-Cloud Reconstruction Report
# data2 沙面点云重建报告

## Objective
## 目标

Reconstruct the sand surface in `data2` as a fast, GPU-based, high-accuracy relative-scale point cloud on an 8GB RTX 5060 Laptop GPU.
在 8GB RTX 5060 笔记本 GPU 上，将 `data2` 中的沙面重建为快速、基于 GPU 的高精度相对尺度点云。

The input images are captured through a rotating observation aperture. Each image sees only part of the sand surface, with large overlap between adjacent views. The main failure modes observed during development were:
输入图像通过旋转观测孔拍摄。每张图像仅能看到沙面的一部分，相邻视角之间存在大量重叠。开发过程中观察到的主要失败模式包括：

- Multi-frame ghosting from unreliable VGGT pose fusion.
- 由于 VGGT 位姿融合不可靠导致的多帧重影。
- Vertical multi-layer point clouds from unmatched per-frame depth scales.
- 由于逐帧深度尺度不匹配导致的垂直多层点云。
- Straight seam artifacts from merging frame boundaries.
- 合并帧边界产生的直线接缝伪影。
- Holes caused by observation-hole occlusions and later point deletion.
- 由观测孔遮挡和后续点删除引起的孔洞。
- Inaccurate aperture-derived edges.
- 不准确的孔径推导边缘。
- Missing sand-grain-scale depth detail in OmniVGGT depth predictions.
- OmniVGGT 深度预测中缺失沙粒级别的深度细节。

## Method
## 方法

### 1. Keyframe Selection
### 1. 关键帧选择

The script builds masks for all images, enhances grayscale with CLAHE, extracts SIFT features, and estimates pairwise homographies with RANSAC.
脚本为所有图像构建掩码，使用 CLAHE 增强灰度，提取 SIFT 特征，并使用 RANSAC 估计两两单应矩阵。

Initial keyframe selection used greedy coverage. This could choose a third frame that left observation-hole occlusions inside the final support. The current version scores candidate 2-3 frame combinations by:
初始关键帧选择使用贪心覆盖策略。这可能会选到第三帧，导致观测孔遮挡残留在最终支撑区域内。当前版本通过对候选的 2-3 帧组合进行评分：

- Union coverage area.
- 联合覆盖面积。
- Canvas compactness.
- 画布紧凑度。
- Internal hole area and hole count penalties.
- 内部孔洞面积和孔洞数量惩罚。
- Graph distance from anchor.
- 距离锚帧的图距离。

With `--anchor_index 3`, the current selected frames are:
使用 `--anchor_index 3`，当前选定的帧为：

```text

Image_20260423192801758.jpg
Image_20260423192942731.jpg
```

This replaced the earlier third frame `Image_20260423192517173.jpg`, which was more likely to leave a visible occlusion hole.
这替换了之前的第三帧 `Image_20260423192517173.jpg`，后者更可能留下可见的遮挡孔洞。

Manual override is available:
可手动覆盖：

```text

```

### 2. Canonical Anchor Canvas
### 2. 规范锚定画布

The reconstruction does not trust OmniVGGT multi-frame camera poses for fusion.
该重建方法不依赖 OmniVGGT 的多帧相机位姿进行融合。

Instead:
而是：

- One selected anchor image defines the canonical 2D coordinate system.
- 选定的锚定图像定义规范的二维坐标系。
- Other frames are aligned to the anchor canvas by homography.
- 其他帧通过单应变换对齐到锚定画布。
- OmniVGGT is used for depth and confidence only.
- OmniVGGT 仅用于深度和置信度。
- Each output XY cell receives at most one fused point.
- 每个输出 XY 单元最多接收一个融合点。

This avoids multi-layer ghosting from imperfect camera pose estimation.
这避免了不完美相机位姿估计导致的多层重影。

### 3. Depth Alignment
### 3. 深度对齐

Per-frame VGGT depths are not directly compatible. The script aligns non-anchor depth maps to the anchor reference using:
逐帧 VGGT 深度并不直接兼容。脚本使用以下方法将非锚定深度图对齐到锚定参考：

- Global affine depth alignment: `z_aligned = scale * z + offset`
- 全局仿射深度对齐：`z_aligned = scale * z + offset`
- Local residual correction in overlap regions
- 重叠区域的局部残差校正
- Anchor depth locking by default: secondary frames cannot bend the anchor reference surface unless `--update_reference_depth` is explicitly enabled.
- 默认锚定深度锁定：除非显式启用 `--update_reference_depth`，否则次级帧不能弯曲锚定参考面。

### 4. Soft Surface Fusion
### 4. 软表面融合

Depth maps are warped into the canonical canvas and fused as a single height field.
深度图被变换到规范画布中，并融合为单一高度场。

Weights use:
权重使用：

- VGGT depth confidence
- VGGT 深度置信度
- Feathered mask distance from frame boundary
- 距帧边界的羽化掩码距离
- Depth consistency against cross-frame consensus
- 与跨帧共识的深度一致性

This is implemented by `--fusion_mode soft_blend`.
通过 `--fusion_mode soft_blend` 实现。

### 5. Plane-Residual Surface Model
### 5. 平面残差表面模型

Because the sand surface is expected to be near-planar, the script fits a robust plane and outputs residual height:
由于沙面预期近似平面，脚本拟合一个稳健平面并输出残差高度：

```text
--surface_model plane_residual
```

High residuals are clipped instead of deleting points:
高残差被裁剪而非删除点：

```text
--plane_residual_mad_multiplier 3.0
```

Earlier versions deleted 1%-99% depth outliers, which could create artificial holes. This has been changed to Z clipping, preserving XY support.
早期版本删除 1%-99% 深度离群值，这可能产生人为孔洞。已改为 Z 裁剪，保留 XY 支撑。

### 6. Support Regularization and Hole Filling
### 6. 支撑正则化与孔洞填充

Observation-hole boundaries are not reliable sand boundaries. The current geometry-first path uses:
观测孔边界并非可靠的沙面边界。当前几何优先路径使用：

```text
--min_support_frames 2
--support_close 81
--hole_fill_max_area 40000
--boundary_trim 36
```

Effects:
效果：

- Requires at least two images to support a region.
- 要求至少两张图像支撑一个区域。
- Closes narrow support gaps caused by rotating aperture occlusions.
- 闭合由旋转孔径遮挡引起的窄支撑间隙。
- Fills internal holes before and after boundary trimming.
- 在边界裁剪前后填充内部孔洞。
- Trims unreliable outer boundary cells.
- 裁剪不可靠的外边界单元。

This produces a thinner, more continuous surface with no detected internal holes in the latest diagnostic.
这产生了更薄、更连续的表面，在最新诊断中未检测到内部孔洞。

### 7. Depth Detail Options
### 7. 深度细节选项

#### Accuracy-first mode
#### 精度优先模式

Use no artificial detail:
不使用人工细节：

```text
--depth_detail_source none
```

This is the current recommended geometry output.
这是当前推荐的几何输出。

#### Geometric residual-flow detail
#### 几何残差流细节

Optional training-free detail:
可选的无需训练细节：

```text
--depth_detail_source parallax_flow
--depth_detail_strength 0.006
--depth_detail_sigma 7
--parallax_flow_scale 0.5
```

This estimates local residual optical flow after homography alignment. It is more defensible than luminance-based detail because it uses multi-view residual parallax, but the scale and sign are still not physically calibrated.
这在单应对齐后估计局部残差光流。它比基于亮度的细节更可靠，因为它使用多视角残差视差，但尺度和符号仍未经过物理校准。

#### Photometric micro-relief
#### 光度微起伏

Photometric detail modes such as `anchor_luma` and `fused_luma` are retained for visualization but are not recommended for accuracy. They can make sand texture visible in Z, but brightness, color, shadows, and reflections are not reliable depth cues. They can also create a thick-looking layer and false edge relief.
光度细节模式如 `anchor_luma` 和 `fused_luma` 保留用于可视化，但不推荐用于精度。它们可以使沙面纹理在 Z 方向上可见，但亮度、颜色、阴影和反射并非可靠的深度线索。它们还可能产生看起来较厚的层和虚假的边缘起伏。

## Observed Causes of Remaining Accuracy Limits
## 观察到的剩余精度限制原因

1. The visible fine texture in the source images is mostly photometric/material texture, not necessarily measurable geometric relief in the available views.
1. 源图像中可见的细纹理主要是光度/材质纹理，在可用视角下不一定是可测量的几何起伏。

2. The image sequence is dominated by rotation through an observation aperture, not a calibrated large-baseline multi-view setup.
2. 图像序列主要是通过观测孔的旋转，而非经过标定的大基线多视角设置。

3. OmniVGGT depth predictions remain relatively smooth on low-texture sand, even at higher input resolution.
3. OmniVGGT 深度预测在低纹理沙面上仍相对平滑，即使在更高的输入分辨率下也是如此。

4. The aperture boundary and black occluders are not true sand boundaries, so output edge accuracy depends on conservative support filtering and trimming.
4. 孔径边界和黑色遮挡物并非真实的沙面边界，因此输出边缘精度依赖于保守的支撑过滤和裁剪。

5. Without camera intrinsics, physical scale, controlled lighting, or a known reference plane, the output is relative-scale geometry.
5. 没有相机内参、物理尺度、受控光照或已知参考平面，输出为相对尺度几何。

## 实用建议

对于精度要求高的结果，避免使用光度微起伏。

For genuinely accurate sand-grain-scale depth, collect additional data with one of these constraints:
要获得真正精确的沙粒级别深度，请使用以下约束之一采集额外数据：

- Fixed camera plus controlled multi-direction lighting for photometric stereo.
- 固定相机加受控多方向光照用于光度立体视觉。
- Structured light or laser line scanning.
- 结构光或激光线扫描。
- Focus stack for shape-from-focus.
- 焦点堆叠用于从聚焦恢复形状。
- Calibrated multi-view capture with a larger known baseline and camera intrinsics.
- 使用更大已知基线和相机内参的标定多视角采集。
- A physical scale/reference plane for metric calibration.
- 用于度量校准的物理尺度/参考平面。

# IEEE Paper Draft

This folder contains an IEEE-style paper draft for the added modules in this project.

- `main.tex`: IEEEtran conference manuscript draft.
- `references.bib`: BibTeX references used by the draft.
- `abstract_zh.md`: Chinese abstract for reporting or presentation materials.

The manuscript frames OmniVGGT as a frozen backend and focuses the contribution on the added streaming, anchor-canvas, depth-alignment, support-fusion, and sand-surface reconstruction modules.
